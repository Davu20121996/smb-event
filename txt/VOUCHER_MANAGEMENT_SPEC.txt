PHẦN 1 — TỔNG QUAN HỆ THỐNG VOUCHER
================================================================================

ĐỊNH NGHĨA:
  Voucher là mã ưu đãi (coupon code) do Ban tổ chức tạo ra và phát cho khách.
  Khách nhập mã khi đăng ký sự kiện để áp dụng ưu đãi tương ứng.

CÁC LOẠI VOUCHER:

  Loại               | Mô tả
  -------------------+---------------------------------------------------------
  DISCOUNT_PERCENT   | Giảm % giá vé. VD: Giảm 20% giá vé VIP
  DISCOUNT_FIXED     | Giảm số tiền cố định. VD: Giảm 100.000đ
  FREE_TICKET        | Vé miễn phí hoàn toàn (giảm 100%)
  GIFT               | Quà tặng vật lý (không ảnh hưởng giá — ghi chú thêm)
  PRIORITY_SEAT      | Ưu tiên chọn chỗ ngồi VIP / hàng đầu

LUỒNG TỔNG QUAN:

  [Admin tạo Voucher trong Admin Panel]
          │
          ▼
  [Admin gán Voucher cho Attendee cụ thể HOẶC phát mã công khai]
          │
          ├── Gán riêng ──► Email tự động gửi mã Voucher đến khách
          │
          └── Mã công khai ──► Khách tự nhập khi đăng ký
                    │
                    ▼
  [Khách nhập mã Voucher tại form đăng ký sự kiện]
          │
          ▼
  [Hệ thống validate: hợp lệ? còn hạn? còn lượt dùng?]
          │
          ├── Hợp lệ ──► Áp dụng ưu đãi → Lưu vào attendees.voucher_id
          │
          └── Không hợp lệ ──► Thông báo lỗi cụ thể cho khách

  [LUỒNG BỔ SUNG — BAN TỔ CHỨC ACTIVE THỦ CÔNG]
          │
          ▼
  [Admin mở trang chi tiết Attendee hoặc danh sách Attendee]
          │
          ▼
  [Nhấn nút ✅ Active Voucher cho khách này]
          │
          ▼
  [Modal xác nhận: Chọn voucher muốn kích hoạt]
          │
          ▼
  [POST /admin/attendees/{id}/activate-voucher]
          │
          ├── Thành công ──► Voucher gắn vào Attendee + Email thông báo
          │
          └── Thất bại   ──► Thông báo lỗi (hết lượt, hết hạn...)

PHẦN 2 — DATABASE SCHEMA (Bảng vouchers)
================================================================================

Bảng: `vouchers`

  Cột                | Kiểu                   | Mô tả
  -------------------+------------------------+----------------------------------
  id                 | bigint PK              |
  event_id           | bigint FK NULL         | Thuộc sự kiện nào (NULL = toàn hệ thống)
  code               | varchar(50) UNIQUE     | Mã voucher. VD: SUMMIT2026VIP
  name               | varchar(255)           | Tên mô tả. VD: "Ưu đãi VIP Early Bird"
  type               | enum                   | discount_percent / discount_fixed / free_ticket / gift / priority_seat
  value              | decimal(10,2)          | Giá trị (% hoặc số tiền). Gift/Priority = 0
  description        | text NULL              | Mô tả chi tiết ưu đãi (hiện cho khách)
  max_uses           | int NULL               | Tổng số lần dùng tối đa (NULL = không giới hạn)
  used_count         | int DEFAULT 0          | Số lần đã được dùng
  is_single_use      | tinyint(1) DEFAULT 0   | 1 = mỗi người chỉ dùng 1 lần
  is_assignable      | tinyint(1) DEFAULT 1   | 1 = có thể gán cho Attendee cụ thể
  valid_from         | datetime NULL          | Thời điểm bắt đầu hiệu lực
  valid_until        | datetime NULL          | Thời điểm hết hạn
  status             | enum                   | active / inactive / expired
  created_by         | bigint FK              | FK → users.id
  created_at         | timestamp              |
  updated_at         | timestamp              |

---

Bảng: `voucher_attendee` (Bảng pivot — gán voucher cho attendee)

  Cột                | Kiểu                   | Mô tả
  -------------------+------------------------+----------------------------------
  id                 | bigint PK              |
  voucher_id         | bigint FK              | FK → vouchers.id
  attendee_id        | bigint FK              | FK → attendees.id
  assigned_by        | bigint FK NULL         | FK → users.id (Admin gán)
  assigned_at        | timestamp              | Thời điểm được gán
  used_at            | timestamp NULL         | Thời điểm khách dùng voucher
  status             | enum                   | assigned / used / expired / revoked

---

Thêm cột vào bảng `attendees`:

  Cột                | Kiểu                   | Mô tả
  -------------------+------------------------+----------------------------------
  voucher_id         | bigint FK NULL         | Voucher đã áp dụng khi đăng ký
  voucher_code       | varchar(50) NULL       | Lưu code tham chiếu (snapshot)
  discount_amount    | decimal(10,2) DEFAULT 0| Số tiền được giảm thực tế

PHẦN 4 — API 2: TẠO VOUCHER MỚI (Create Voucher)
================================================================================

ENDPOINT : POST /admin/vouchers
MỤC ĐÍCH : Admin tạo voucher mới cho sự kiện.

REQUEST BODY:
  {
    "event_id"      : 3,
    "code"          : "SUMMIT2026VIP",
    "name"          : "Ưu đãi VIP Early Bird",
    "type"          : "discount_percent",
    "value"         : 20,
    "description"   : "Giảm 20% giá vé VIP cho 50 khách đăng ký sớm",
    "max_uses"      : 50,
    "is_single_use" : true,
    "valid_from"    : "2026-08-01 00:00:00",
    "valid_until"   : "2026-09-01 23:59:59",
    "status"        : "active"
  }

VALIDATION:
  - code         : required | string | unique:vouchers,code | max:50 | uppercase
  - name         : required | string | max:255
  - type         : required | in:discount_percent,discount_fixed,free_ticket,gift,priority_seat
  - value        : required_if:type,discount_percent,discount_fixed | numeric | min:0
  - max_uses     : nullable | integer | min:1
  - valid_from   : nullable | date
  - valid_until  : nullable | date | after:valid_from
  - status       : required | in:active,inactive

TÍNH NĂNG BỔ SUNG — TỰ ĐỘNG SINH MÃ:
  Nếu không nhập code, hệ thống tự sinh mã ngẫu nhiên:
  format: "{EVENT_PREFIX}-{RANDOM_6}" VD: "TSM-K9P2X1"

RESPONSE — Thành công (201):
  {
    "status"  : "success",
    "message" : "Tạo voucher thành công.",
    "data"    : { /* voucher object */ }
  }

RESPONSE — Trùng mã (422):
  {
    "status"  : "error",
    "message" : "Mã voucher 'SUMMIT2026VIP' đã tồn tại trong hệ thống."
  }

PHẦN 6 — API 4: GÁN VOUCHER CHO ATTENDEE (Assign Voucher)
================================================================================

ENDPOINT : POST /admin/vouchers/{id}/assign
MỤC ĐÍCH : Admin gán voucher cho 1 hoặc nhiều Attendee cụ thể.
           Sau khi gán, hệ thống tự gửi email thông báo voucher cho khách.

REQUEST BODY:
  {
    "attendee_ids" : [12, 45, 78],
    "send_email"   : true,
    "note"         : "Tặng voucher VIP cho khách mời đặc biệt"
  }

VALIDATION:
  - attendee_ids : required | array | min:1
  - attendee_ids.* : exists:attendees,id
  - send_email   : boolean

XỬ LÝ LOGIC:
  1. Kiểm tra voucher còn lượt dùng không (used_count < max_uses hoặc max_uses = null)
  2. Kiểm tra từng attendee_id có tồn tại không
  3. Kiểm tra attendee chưa được gán voucher này (tránh gán trùng)
  4. INSERT vào bảng voucher_attendee
  5. Nếu send_email = true → Queue job gửi email cho từng khách

RESPONSE — Thành công (200):
  {
    "status"  : "success",
    "message" : "Đã gán voucher cho 3 khách.",
    "assigned": [
      { "attendee_id": 12, "name": "Nguyễn Văn A", "email": "a@abc.com", "email_sent": true },
      { "attendee_id": 45, "name": "Trần Thị B",   "email": "b@abc.com", "email_sent": true }
    ],
    "skipped" : [
      { "attendee_id": 78, "reason": "Đã được gán voucher này trước đó" }
    ]
  }

RESPONSE — Hết lượt dùng (422):
  {
    "status"  : "error",
    "code"    : "VOUCHER_EXHAUSTED",
    "message" : "Voucher chỉ còn 2 lượt dùng, không đủ để gán cho 3 khách."
  }

PHẦN 7 — API 5: NHẬN / ÁP DỤNG VOUCHER (Redeem Voucher)
================================================================================

ENDPOINT : POST /api/vouchers/validate
MỤC ĐÍCH : Khách nhập mã voucher tại form đăng ký — hệ thống kiểm tra
           và trả về thông tin ưu đãi để hiển thị trước khi submit.

           (KHÔNG PHẢI Public API — chỉ dùng trong form đăng ký có session)

REQUEST BODY:
  {
    "code"     : "SUMMIT2026VIP",
    "event_id" : 3,
    "email"    : "nguyenvana@example.com"   ← Dùng kiểm tra is_single_use
  }

XỬ LÝ LOGIC (theo thứ tự):
  1. Tìm voucher theo code
     → Không tìm thấy: Lỗi "Mã voucher không hợp lệ"
  2. Kiểm tra event_id khớp (nếu voucher thuộc event cụ thể)
     → Không khớp: Lỗi "Mã voucher không áp dụng cho sự kiện này"
  3. Kiểm tra status = 'active'
     → Không: Lỗi "Mã voucher đã bị vô hiệu hóa"
  4. Kiểm tra valid_from ≤ now() ≤ valid_until
     → Chưa đến hạn: Lỗi "Mã voucher chưa có hiệu lực"
     → Hết hạn: Lỗi "Mã voucher đã hết hạn"
  5. Kiểm tra used_count < max_uses (nếu max_uses != null)
     → Lỗi: "Mã voucher đã hết lượt sử dụng"
  6. Kiểm tra is_single_use: email này đã dùng voucher này chưa?
     → Lỗi: "Email của bạn đã sử dụng mã voucher này"
  7. Hợp lệ → Trả về thông tin ưu đãi

RESPONSE — Hợp lệ (200):
  {
    "status" : "valid",
    "voucher": {
      "code"          : "SUMMIT2026VIP",
      "name"          : "Ưu đãi VIP Early Bird",
      "type"          : "discount_percent",
      "value"         : 20,
      "description"   : "Giảm 20% giá vé VIP cho khách đăng ký sớm",
      "discount_label": "Giảm 20%"
    }
  }

RESPONSE — Không hợp lệ (422):
  {
    "status"  : "invalid",
    "code"    : "VOUCHER_EXPIRED",      ← Mã lỗi cụ thể
    "message" : "Mã voucher đã hết hạn sử dụng."
  }

---

ENDPOINT : POST /api/vouchers/apply
MỤC ĐÍCH : Áp dụng voucher chính thức khi khách submit form đăng ký.
           Gọi đồng thời với việc tạo Attendee.

XỬ LÝ LOGIC:
  1. Validate lại toàn bộ (tương tự /validate — tránh race condition)
  2. Tạo Attendee với voucher_id, voucher_code, discount_amount
  3. Tăng used_count của voucher lên 1
  4. Cập nhật voucher_attendee.used_at = now() (nếu là voucher gán riêng)
  5. Trả về Attendee đã tạo

RESPONSE — Thành công (201):
  {
    "status"         : "success",
    "message"        : "Đăng ký thành công với mã ưu đãi SUMMIT2026VIP.",
    "attendee_id"    : 42,
    "discount_applied": "Giảm 20% — tiết kiệm 200.000đ"
  }

PHẦN 11 — EMAIL THÔNG BÁO VOUCHER CHO KHÁCH
================================================================================

KÍCH HOẠT: Khi Admin gán voucher và tick "Gửi email thông báo"

NỘI DUNG EMAIL:
  - Tiêu đề: "🎁 Bạn nhận được voucher ưu đãi từ [Tên Sự Kiện]"
  - Kính gửi [Tên khách]
  - Thông báo đã nhận voucher
  - Hiển thị nổi bật: MÃ VOUCHER (font lớn, có thể copy)

PHẦN 15 — API: ACTIVE VOUCHER THỦ CÔNG (Ban Tổ Chức Kích Hoạt Cho Khách)
================================================================================

MỤC ĐÍCH:
  Ban tổ chức không cần chờ khách tự nhập mã.
  Admin vào trang quản lý Attendee, nhấn nút [✅ Active Voucher] để gắn
  voucher trực tiếp vào tài khoản của khách cụ thể đó.

TRƯỜNG HỢP SỬ DỤNG:
  - Khách VIP được tặng voucher đặc biệt không công khai
  - Khách gặp sự cố không nhập được mã → Admin active giúp
  - Ban tổ chức muốn áp dụng ưu đãi hàng loạt cho nhóm khách

--------------------------------------------------------------------------------
15.1. API ACTIVE VOUCHER (POST)
--------------------------------------------------------------------------------

ENDPOINT : POST /admin/attendees/{attendee_id}/activate-voucher
MỤC ĐÍCH : Kích hoạt và gắn voucher vào 1 Attendee cụ thể.

REQUEST BODY:
  {
    "voucher_id"   : 5,
    "send_email"   : true,
    "note"         : "Voucher tặng thêm cho khách VIP đặc biệt"
  }

VALIDATION:
  - voucher_id : required | exists:vouchers,id
  - send_email : boolean
  - note       : nullable | string | max:500

XỬ LÝ LOGIC:
  1. Tìm Attendee theo attendee_id
  2. Tìm Voucher theo voucher_id
  3. Kiểm tra Voucher còn hiệu lực:
     - status = 'active'
     - now() nằm trong valid_from → valid_until
     - used_count < max_uses (nếu max_uses != null)
  4. Kiểm tra Attendee chưa có voucher nào (attendee.voucher_id == null)
     → Nếu đã có: hỏi xác nhận ghi đè (trả về warning trước)
  5. Gắn voucher vào Attendee:
     $attendee->update([
         'voucher_id'      => $voucher->id,
         'voucher_code'    => $voucher->code,
         'discount_amount' => calculateDiscount($voucher, $attendee),
     ])
  6. Ghi vào voucher_attendee: status = 'used', used_at = now()
  7. Tăng voucher.used_count += 1
  8. Ghi log: ai active, lúc nào, lý do
  9. Nếu send_email = true → Gửi email thông báo voucher cho khách

RESPONSE — Thành công (200):
  {
    "status"  : "success",
    "message" : "Đã kích hoạt voucher SUMMIT2026VIP cho Nguyễn Văn A.",
    "data": {
      "attendee_name"     : "Nguyễn Văn A",
      "voucher_code"      : "SUMMIT2026VIP",
      "voucher_name"      : "Ưu đãi VIP Early Bird",
      "discount_applied"  : "Giảm 20% — 200.000đ",
      "email_sent"        : true
    }
  }

RESPONSE — Attendee đã có voucher (409):
  {
    "status"  : "warning",
    "code"    : "ALREADY_HAS_VOUCHER",
    "message" : "Khách này đã có voucher 'GIFT25' đang áp dụng. Bạn có muốn thay thế?",
    "current_voucher": {
      "code"  : "GIFT25",
      "name"  : "Voucher quà tặng"
    }
  }
  → Frontend hiển thị modal xác nhận: [Hủy] [Thay thế voucher cũ]
  → Nếu xác nhận thay thế: gửi lại request kèm "force": true

RESPONSE — Voucher hết lượt (422):
  {
    "status"  : "error",
    "code"    : "VOUCHER_EXHAUSTED",
    "message" : "Voucher này đã hết lượt sử dụng."
  }

RESPONSE — Voucher hết hạn (422):
  {
    "status"  : "error",
    "code"    : "VOUCHER_EXPIRED",
    "message" : "Voucher này đã hết hạn sử dụng."
  }

15.3. API THU HỒI VOUCHER (Revoke)
--------------------------------------------------------------------------------

ENDPOINT : POST /admin/attendees/{attendee_id}/revoke-voucher
MỤC ĐÍCH : Thu hồi voucher đang gắn vào 1 Attendee (trong trường hợp nhầm).

REQUEST BODY:
  {
    "reason": "Gán nhầm voucher — khách không thuộc nhóm này"
  }

XỬ LÝ LOGIC:
  1. Tìm Attendee → lấy voucher_id hiện tại
  2. Reset: attendee.voucher_id = null, voucher_code = null, discount_amount = 0
  3. Giảm voucher.used_count -= 1
  4. Cập nhật voucher_attendee.status = 'revoked'
  5. Ghi log thu hồi

RESPONSE (200):
  {
    "status"  : "success",
    "message" : "Đã thu hồi voucher SUMMIT2026VIP của Nguyễn Văn A."
  }
