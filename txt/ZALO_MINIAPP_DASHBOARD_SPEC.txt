================================================================================
        XÂY DỰNG API DASHBOARD CHO ZALO MINI APP
   (Thông Tin Khách · Trạng Thái Check-in · Voucher · Survey)
        + GIAO DIỆN ADMIN QUẢN LÝ & THEO DÕI
================================================================================

Phạm vi: Thiết kế toàn bộ API phục vụ Zalo Mini App hiển thị dashboard cá nhân
cho từng khách tham dự sự kiện, đồng thời xây dựng giao diện Admin để Ban tổ
chức theo dõi dữ liệu realtime.

================================================================================
PHẦN 1 — TỔNG QUAN KIẾN TRÚC
================================================================================

MÔ HÌNH HOẠT ĐỘNG:

  [Khách mở Zalo Mini App]
          │
          ▼
  [Zalo Mini App gọi API với zalo_user_id / phone]
          │
          ▼
  [Laravel API Server]
          │
          ├── /api/zalo/me            → Thông tin cá nhân + đăng ký sự kiện
          ├── /api/zalo/checkin       → Trạng thái Check-in
          ├── /api/zalo/voucher       → Voucher đang áp dụng
          ├── /api/zalo/survey        → Danh sách Survey cần điền
          └── /api/zalo/dashboard     → Tổng hợp tất cả (1 request duy nhất)

  [Admin mở trang /admin/zalo-dashboard]
          │
          ▼
  [Xem realtime: Tổng khách, Check-in, Voucher, Survey]

AUTH CHO ZALO MINI APP:
  - Zalo Mini App gửi kèm: zalo_access_token (JWT từ Zalo)
  - Backend verify token với Zalo API → lấy zalo_user_id
  - Map zalo_user_id với attendees.zalo_user_id trong DB
  - Fallback: khách cung cấp phone/email để xác định tài khoản

THÊM CỘT VÀO BẢNG attendees:
  Cột              | Kiểu          | Mô tả
  -----------------+---------------+----------------------------------
  zalo_user_id     | varchar(50)   | ID Zalo của khách (liên kết Mini App)
  zalo_linked_at   | timestamp NULL| Thời điểm liên kết Zalo

================================================================================
PHẦN 2 — API DASHBOARD TỔNG HỢP (1 Request Duy Nhất)
================================================================================

ENDPOINT : GET /api/zalo/dashboard
MỤC ĐÍCH : Lấy toàn bộ thông tin khách trong 1 lần gọi — tối ưu cho Zalo Mini App.
AUTH     : Zalo Access Token (Header: Authorization: Bearer {zalo_token})

QUERY PARAMS:
  - event_id : (optional) Lọc theo sự kiện cụ thể

XỬ LÝ LOGIC:
  1. Verify Zalo Access Token → lấy zalo_user_id
  2. Tìm Attendee::where('zalo_user_id', $zalo_user_id)->with([
       'event', 'voucher', 'surveyResponses', 'checkinLog'
     ])->first()
  3. Nếu không tìm thấy → trả về 404 "Bạn chưa đăng ký sự kiện nào"
  4. Tổng hợp dữ liệu từ tất cả module → trả về 1 JSON

RESPONSE — Thành công (200):
  {
    "status": "ok",
    "data": {
      "profile"  : { /* Thông tin khách — Phần 3 */ },
      "checkin"  : { /* Trạng thái Check-in — Phần 4 */ },
      "voucher"  : { /* Voucher — Phần 5 */ },
      "survey"   : { /* Survey — Phần 6 */ },
      "event"    : { /* Thông tin sự kiện — Phần 7 */ }
    },
    "generated_at": "2026-09-15 08:30:00"
  }

RESPONSE — Chưa đăng ký (404):
  {
    "status" : "not_found",
    "message": "Bạn chưa đăng ký tham dự sự kiện nào.",
    "action" : "Vui lòng đăng ký qua form tại trang sự kiện."
  }

// Public API cho Zalo Mini App
Route::prefix('api/zalo')->middleware(['zalo.auth'])->name('api.zalo.')
     ->group(function () {

    Route::get('/dashboard', [ZaloDashboardApiController::class, 'dashboard'])
         ->name('dashboard');                    // Tổng hợp tất cả

    Route::get('/me',        [ZaloDashboardApiController::class, 'me'])
         ->name('me');                           // Thông tin khách

    Route::get('/qr-code',   [ZaloDashboardApiController::class, 'qrCode'])
         ->name('qr-code');                      // Ảnh QR PNG

    Route::get('/checkin',   [ZaloDashboardApiController::class, 'checkin'])
         ->name('checkin');                      // Trạng thái check-in

    Route::get('/voucher',   [ZaloDashboardApiController::class, 'voucher'])
         ->name('voucher');                      // Voucher của khách

    Route::post('/voucher/redeem', [ZaloDashboardApiController::class, 'redeemVoucher'])
         ->name('voucher.redeem');               // Khách nhập mã voucher qua app

    Route::get('/survey',    [ZaloDashboardApiController::class, 'survey'])
         ->name('survey');                       // Danh sách survey

    Route::post('/survey/{id}/submit', [ZaloDashboardApiController::class, 'submitSurvey'])
         ->name('survey.submit');               // Nộp bài survey

PHẦN 12 — MIDDLEWARE ZALO AUTH (zalo.auth)
================================================================================

File: app/Http/Middleware/ZaloAuthMiddleware.php

Xử lý:
  1. Lấy Bearer token từ Header: Authorization
  2. Gọi Zalo API: GET https://graph.zalo.me/v2.0/me?access_token={token}
     → Trả về: { "id": "zalo_user_id", "name": "...", "picture": {...} }
  3. Tìm Attendee::where('zalo_user_id', $zaloUserId)->first()
  4. Nếu chưa liên kết:
     - Tìm theo phone (nếu Zalo cung cấp số điện thoại)
     - Nếu tìm thấy → tự động liên kết: attendee->zalo_user_id = $zaloUserId
     - Nếu không tìm thấy → trả về 404
  5. Set $request->attendee = $attendee để controller dùng

RESPONSE lỗi token (401):
  {
    "status"  : "unauthorized",
    "message" : "Zalo token không hợp lệ hoặc đã hết hạn."
  }
